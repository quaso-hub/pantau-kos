Kamu perlu clone repo di PythonAnywhere. Caranya:

## BUKA BASH CONSOLE

1. Login ke https://www.pythonanywhere.com
2. Lihat button biru: **"Open Bash console here"** (di halaman Files)
3. KLIK itu

## JALANKAN INI (copy-paste, satu baris):

```
cd ~ && git clone https://github.com/quaso-hub/pantau-kos.git kost-bot && cd kost-bot && ls -la
```

Hanya 1 baris! Copy-paste aja!
